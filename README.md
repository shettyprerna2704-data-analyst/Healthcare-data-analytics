# Healthcare Data Analytics | SQL, Python & Power BI

An end-to-end analysis of US healthcare patient and claims data, using **Python, PostgreSQL and Power BI** to explore healthcare costs, insurance coverage, patient demographics, claims trends and provider performance.

## Tech Stack
- **Python:** Pandas, NumPy, Jupyter Notebook
- **Database:** PostgreSQL
- **Visualisation:** Power BI

## Project Workflow
1. **Data Cleaning:** Cleaned and standardised healthcare datasets using Python.
2. **Exploratory Analysis:** Examined missing values, distributions and data quality.
3. **Database Management:** Created and populated a relational PostgreSQL database.
4. **SQL Analysis:** Executed 20 business queries covering healthcare costs, insurance payments, readmissions, claims and physician performance.
5. **Automation:** Used Python to execute SQL queries and export results to CSV.
6. **Data Visualisation:** Developed a four-page interactive Power BI report.

## Power BI Dashboard

| Dashboard Page | Focus |
|---|---|
| **Financial Overview** | Healthcare expenditure, insurance coverage and payment trends |
| **Clinical & Hospital Performance** | Patient volumes, medical specialties and physician costs |
| **Claims & Revenue Analysis** | Claims trends, outstanding balances, delayed postings and adjustments |
| **Patient & Insurance Insights** | Patient payments, demographics and geographic variations |
